## 故障排查

### 问题 1：点击山形按钮没反应

**可能原因：**
- 地形数据未生成
- API 端点未启动
- 当前区域没有地形数据

**解决方法：**
```bash
# 生成地形数据
cd meteo-viz/crawler
python fetch_terrain.py --adcodes 100000 510000 530000

# 检查数据文件
ls ../data/terrain/
```

### 问题 2：地形效果不明显

**原因：** 夸张系数设置

**解决：** 修改 `web/js/sand-scene.js` 第 168 行左右：
```javascript
const elevationScale = this.span * 0.15;  // 默认 15%
// 改为：
const elevationScale = this.span * 0.25;  // 增大到 25%
```

### 问题 3：加载地形后页面卡顿

**原因：** 顶点计算量大

**解决：** 降低地形分辨率
```bash
python fetch_terrain.py --adcodes 100000 --resolution 64  # 从128降到64
```

### 问题 4：控制台报错 "Mountain is not defined"

**原因：** lucide 图标库缺少 Mountain 图标

**解决：** 使用现有图标代替，修改 `sandtable.js` 模板：
```javascript
// 将 v-html="icon('Mountain')" 改为：
v-html="icon('Triangle')"  // 或其他可用图标
```

## 技术细节

### 地形数据格式

```json
{
  "adcode": "510000",
  "width": 128,
  "height": 128,
  "min": 0.0,
  "max": 4170.0,
  "mean": 1261.0,
  "data": [0, 15, 32, ...] // 16384 个高程值
}
```

### 前端渲染流程

1. 用户点击山形按钮
2. `toggleTerrain()` 方法调用
3. 异步加载地形数据 `loadTerrain(adcode)`
4. 应用高程到网格 `applyTerrain()`
5. 遍历所有区域 mesh
6. 双线性插值采样每个顶点的高程
7. 修改顶点 Y 坐标
8. 重新计算法线
9. 刷新渲染

### 关键代码片段

**加载地形：**
```javascript
async loadTerrain(adcode) {
  const response = await fetch(`/api/terrain/${adcode}`);
  this.terrainData = await response.json();
  return this.terrainData;
}
```

**应用高程：**
```javascript
applyTerrain() {
  const elevationScale = this.span * 0.15;
  this.regionMeshes.forEach(meshes => {
    meshes.forEach(mesh => {
      const positions = mesh.geometry.attributes.position;
      for (let i = 0; i < positions.count; i++) {
        const elevation = this.sampleElevation(lon, lat);
        const heightOffset = ((elevation - min) / (max - min)) * elevationScale;
        positions.setY(i, positions.getY(i) + heightOffset);
      }
      positions.needsUpdate = true;
      geometry.computeVertexNormals();
    });
  });
}
```
