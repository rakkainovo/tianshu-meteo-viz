- ✅ 地形数据生成脚本：`crawler/fetch_terrain.py`

#### 使用方法
1. 访问 http://127.0.0.1:5000/#/sandtable
2. 点击右上角工具栏的**山形图标按钮**（在 3D/2D 切换旁边）
3. 等待地形数据加载（首次加载约 1-2 秒）
4. 观察地图立体效果：西部高原抬升，东部平原低平

## 🔧 可能遇到的问题

### 问题 1：点击按钮没反应

**检查项：**
1. 浏览器控制台是否有错误
2. 是否在 3D 视图下（2D 视图下按钮禁用）
3. 网络请求是否成功（F12 → Network 查看）

**解决方法：**
```bash
# 检查服务是否运行
curl http://127.0.0.1:5000/api/terrain/100000

# 重新生成地形数据
cd crawler
python fetch_terrain.py --adcodes 100000
```

### 问题 2：地形效果不明显

**原因：** 当前区域地形较平坦（如北京）

**解决：** 切换到山区省份测试：
- 四川（510000）
- 云南（530000）
- 西藏（540000）

### 问题 3：加载缓慢

**原因：** 地形数据较大（约 300KB/省份）

**优化：**
1. 降低分辨率：`--resolution 64`
2. 启用数据压缩（已在计划中）
