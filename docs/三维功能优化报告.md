- 添加半透明的影响范围圆圈

## 💻 技术实现

### 地形数据生成

```python
# 生成所有省份地形数据
python fetch_terrain.py --all

# 生成结果：
# - 364 个 JSON 文件
# - 每个文件 128x128 分辨率
# - 基于地理特征的程式化模型
# - 总耗时约 7.4 秒
```

### 台风云墙实现

```javascript
// 云墙效果层
if (this.cloud3d && cp.level) {
  series.push({
    name: '台风云墙',
    type: 'effectScatter',
    symbolSize: getRadiusForLevel(cp.level),
    rippleEffect: { scale: 2.5, period: 4 },
    itemStyle: { opacity: 0.15, shadowBlur: 30 }
  });
}

// 强度到半径映射
getRadiusForLevel(level) {
  return {
    'TD': 30, 'TS': 40, 'STS': 50,
    'TY': 60, 'STY': 70, 'SuperTY': 85
  }[level] || 40;
}
```
