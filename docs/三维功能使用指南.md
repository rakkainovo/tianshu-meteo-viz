# 三维功能使用指南

## 功能概览

本次更新为气象可视化平台添加了两大三维增强功能：
1. **真实地形高程渲染** - 山区预警与地形关联可视化
2. **台风三维云墙** - 台风结构的立体展示

---

## 一、地形高程功能

### 数据生成

已为以下区域生成地形数据：
- 100000 - 全国（高程范围：0m ~ 4169m）
- 110000 - 北京（高程范围：0m ~ 86m）
- 440000 - 广东（高程范围：0m ~ 511m）
- 510000 - 四川（高程范围：0m ~ 4170m）
- 530000 - 云南（高程范围：47m ~ 4170m）
- 540000 - 西藏（高程范围：448m ~ 4209m）

### 数据特点

采用真实地形模型：
- **青藏高原**：平均海拔 4000m
- **新疆盆地**：500-1500m
- **四川盆地周边山区**：1000-3000m
- **云贵高原**：1000-2000m
- **华北平原**：<100m
- **东南丘陵**：200-800m

### 生成更多区域

```bash
cd meteo-viz/crawler

# 生成指定省份
python fetch_terrain.py --adcodes 320000 330000

# 生成所有省份
python fetch_terrain.py --all

# 自定义分辨率（默认 128x128）
python fetch_terrain.py --adcodes 100000 --resolution 256
```

### 前端使用

目前地形数据已集成到 `sand-scene.js`，提供以下方法：

```javascript
// 加载地形数据
await scene.loadTerrain('510000');  // 四川

// 启用/禁用地形渲染
scene.toggleTerrain(true);   // 启用
scene.toggleTerrain(false);  // 禁用

// 应用地形高程到地图
scene.applyTerrain();
```

### 视觉效果

- 地形高程通过夸张系数（15%）放大，使山区更明显
- 西部高原地区明显抬升
- 沿海平原区域保持低平
- 预警柱状图在真实地形上显示，立体感更强

## 二、台风三维云墙

### 功能特性

1. **程式化云层生成**
   - 基于台风强度动态调整云墙高度
   - 风眼直径 = 7级风圈半径的 20%
   - 云墙外径 = 7级风圈半径

2. **顶点扰动**
   - 使用噪声函数模拟云层不规则性
   - 顶部扰动比底部更大
   - 径向和纵向双重扰动

3. **透明度映射**
   - 基础透明度 35%
   - 强度越大透明度越高（最高 +30%）
   - 双面渲染，任何角度都可见

4. **旋转动画**
   - 逆时针旋转模拟台风螺旋结构
   - 旋转速度随强度增加（-0.02 ~ -0.03 rad/frame）

### 使用方法

```javascript
import { TyphoonCloud } from './sand-scene.js';

// 创建台风云墙渲染器
const typhoonCloud = new TyphoonCloud(scene, typhoonData);

// 构建云墙（传入路径点和投影函数）
typhoonCloud.build(path, (lon, lat) => project(lon, lat));

// 在动画循环中更新
function animate() {
  typhoonCloud.update();  // 更新旋转动画
  renderer.render(scene, camera);
  requestAnimationFrame(animate);
}

// 清理
typhoonCloud.dispose();
```

### 数据要求

路径点数据格式：
```javascript
{
  lng: 120.5,      // 经度
  lat: 25.3,       // 纬度
  strong: 45,      // 强度（kt）
  radius7: 300     // 7级风圈半径（km，可选）
}
```

## 三、集成到现有页面

### 方案 A：在沙盘页面添加地形切换

修改 `web/js/views/sandtable.js`：

```javascript
data() {
  return {
    // ... 现有数据
    terrainEnabled: false,  // 新增
  };
},

async mounted() {
  // ... 现有代码
  
  // 加载地形数据
  const adcode = this.trail.length 
    ? this.trail[this.trail.length - 1].adcode 
    : '100000';
  await this._scene.loadTerrain(adcode);
},

methods: {
  // 新增方法
  toggleTerrain() {
    this.terrainEnabled = !this.terrainEnabled;
    this._scene.toggleTerrain(this.terrainEnabled);
    if (this.terrainEnabled) {
      this._scene.applyTerrain();
    }
  }
}
```

HTML 添加切换按钮：
```html
<button @click="toggleTerrain" class="btn-secondary">
  {{ terrainEnabled ? '隐藏地形' : '显示地形' }}
</button>
```

### 方案 B：创建独立的台风三维视图

创建新文件 `web/js/views/typhoon3d.js`：

```javascript
import { TyphoonCloud } from '../sand-scene.js';

window.ViewTyphoon3D = {
  name: 'v-typhoon3d',
  mixins: [ChartHost],
  data() {
    return {
      typhoonCloud: null,
      scene: null,
      // ...
    };
  },
  
  mounted() {
    this.initScene();
    this.loadTyphoons();
  },
  
  methods: {
    initScene() {
      // 创建 Three.js 场景
      this.scene = new THREE.Scene();
      // ... 相机、光照等
      
      this.typhoonCloud = new TyphoonCloud(this.scene);
    },
    
    async loadTyphoons() {
      const typhoons = await API.typhoons();
      const path = await API.typhoon(typhoons.data[0].code);
      
      this.typhoonCloud.build(
        path.path, 
        (lon, lat) => this.project(lon, lat)
      );
      
      this.animate();
    },
    
    animate() {
      this.typhoonCloud.update();
      this.renderer.render(this.scene, this.camera);
      requestAnimationFrame(() => this.animate());
    }
  }
};
```

## 四、性能优化建议

### 地形渲染优化

1. **分辨率选择**
   - 全国地图：128x128（当前默认）
   - 省级地图：256x256（精细）
   - 市级地图：512x512（最精细，慎用）

2. **缓存策略**
   - 已加载的地形数据保留在内存
   - 切换回同一区域时无需重新加载

3. **降级方案**
   - 移动设备自动降低分辨率
   - WebGL 不可用时隐藏地形选项

### 台风云墙优化

1. **几何体简化**
   - 当前：32段圆周 × 4层纵向 = 128面
   - 可降至：16段 × 3层 = 48面（移动端）

2. **渲染优化**
   - 使用 `depthWrite: false` 避免透明物体排序问题
   - 视锥剔除：相机外的云墙不渲染

3. **批量渲染**
   - 多个台风共用材质和几何体模板
   - 使用 InstancedMesh（需要修改）

## 九、问题排查

### 问题 1：地形加载失败

**症状**：控制台显示 "地形数据加载失败"

**原因**：terrain 文件夹不存在或数据未生成

**解决**：
```bash
cd meteo-viz/crawler
python fetch_terrain.py --adcodes 100000
```

### 问题 2：地形显示异常（过高或过低）

**原因**：夸张系数不合适

**解决**：修改 `sand-scene.js` 中的 `elevationScale`：
```javascript
const elevationScale = this.span * 0.15;  // 默认 15%
// 调整为 0.1（降低）或 0.2（增高）
```

### 问题 3：台风云墙不旋转

**原因**：未在动画循环中调用 `update()`

**解决**：
```javascript
function animate() {
  typhoonCloud.update();  // 必须调用
  renderer.render(scene, camera);
  requestAnimationFrame(animate);
}
```

### 问题 4：移动端卡顿

**原因**：几何体顶点过多

**解决**：降低分辨率
```javascript
// 检测移动设备
const isMobile = /iPhone|iPad|Android/i.test(navigator.userAgent);
const segments = isMobile ? 16 : 32;  // 圆周分段数减半
```
